Service Cloud process overview

Focus on case lifecycle, queue routing, knowledge search, and service metrics.

Case Management Essentials

Cases track customer issues across support teams. Understand case statuses, priorities, record types, and queues.

Case Object

  • Subject / Description capture the issue.
  • Status tracks stage: New, Working, Escalated, Closed.
  • Priority indicates urgency.
  • Case Owner handles assignment and routing.

Support Processes

  • Case assignment rules route cases to queues or users.
  • Auto-response rules send immediate email replies.
  • Escalation rules create tasks or alerts for overdue cases.
  • Case teams give shared access to multiple agents.

Developer Notes

  • Use record-triggered flows for simple case automation.
  • Use Apex when logic spans multiple objects or external systems.
  • Respect case assignment and sharing model in automation.

Service Console & Agent Productivity

The console is the main workspace for support agents. Know the key components and how they speed case work.

Console Features

  • Tabbed workspaces let agents switch cases quickly.
  • Utility bar provides quick access to common tools.
  • Related records and quick actions appear on the same page.

Useful Elements

  • Case Feed shows history, emails, and chatter updates.
  • Macros automate repetitive tasks.
  • Quick Text inserts pre-approved replies.

Implementation Tips

  • Use Lightning App Builder to customize the console layout.
  • Compact layouts improve data visibility on record headers.
  • Use global actions for high-value support tools (e.g., create case).

Knowledge Management

Knowledge articles reduce case volume by giving agents and customers the right answers.

Article Basics

  • Articles are grouped by data category and article type.
  • Use record types to define different article structures.
  • Publish articles in draft, review, or published status.

Search & Access

  • Knowledge search uses keywords and categories.
  • Data categories control article visibility by profile.
  • Article actions include translate, archive, and publish.

Developer Notes

  • Use article types for structured knowledge content.
  • Keep article versions clean and archive outdated content.
  • Use Experience Cloud for customer-facing knowledge portals.

Omni-Channel & Routing

Omni-Channel routes work items to available agents. It is the backbone of modern service operations.

Omni-Channel Basics

  • Work items include cases, chats, leads, and custom objects.
  • Presence statuses indicate agent availability.
  • Routing configurations determine who receives work.

Queue & Skill-Based Routing

  • Queues hold work items until an agent accepts them.
  • Skills let you route to agents with special expertise.
  • Capacity models control how many items an agent can handle.

Service Cloud Best Practices

  • Start with simple queue-based routing, then refine with skills.
  • Use service goals for response time and remaining work.
  • Test Omni-Channel in a sandbox before production rollout.
